# Customer hand photo workflow — test fixtures

These screenshots use independent schematic hands made with Sharp for automated
transport/geometry tests. They are not real customer photos, standard avatar
hands, live Gemini output or evidence of realistic image-generation quality.
The generator is mocked to preserve the uploaded fixture, allowing the tests to
verify one-credit metering, markers, approval, persistence and reopening.

- [Marker editor on mobile](markers-mobile.png)
- [Approved hands on mobile](approved-mobile.png)
- [Approved hands on desktop](approved-desktop.png)

The local presence heuristic also passes twelve existing male/female template
assets and six schematic complexion colours in unit tests. This does not
establish accuracy/fairness on real photos or replace customer/staff review.
